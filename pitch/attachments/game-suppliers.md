# Artifact A — Traditional Game Suppliers (prospects for selling/licensing Monkify)

## How to use this for the pitch task

This is a ranked shortlist of established B2B iGaming game suppliers and content aggregators — the "traditional supplier" channel for licensing/distributing Monkify to many operators through a single integration. Because these are regulated-market suppliers, the PF/regulatory filter bites harder here than for crypto-native targets, so **Tier reflects near-term reachability + appetite for a novel real-time multiplayer format + inverse clone-risk**, not raw scale. Entries are ordered best-fit first (Tier 1 → Tier 3, by fit within tier). Each profile carries a verified BD/intake channel, an honest read on the certification gap (Monkify is provably-fair-ready with certification in progress), and a pitch angle. The downstream per-target pitch task should consume each profile's **Contact** (respecting the Verified/Inferred/Unverified status on every item — never guess an email), **How they onboard 3rd-party games**, and **Pitch angle** fields as the starting scaffold, and lead with the crypto-adjacent / lighter-regulation entry lane wherever one is flagged.
