# Chat per Game Type Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move game chat from a per-round SignalR group to a per-game-type room with a Redis-backed, retention-bounded last-100 history (`GET /games/{parametersId}/chat`), and fix one How-to-Play line.

**Architecture:** The API hub validates the room against the cached active-type catalogue, broadcasts to `chat:{gameTypeId}`, appends to a per-type Redis list (`IChatHistoryStore`) and publishes the existing persist event (now carrying id/type/round/sentAt). A new MediatR handler serves history from the list and falls back to Postgres on a miss. The Vue client joins the type room once (independent of round rollover), then fetches history and merges by server id.

**Tech Stack:** .NET 8, ASP.NET Core SignalR, EF Core (Npgsql), StackExchange.Redis, MediatR, MassTransit (Postgres transport), xUnit + Shouldly + Moq, Testcontainers; Vue 3 + TypeScript, `@microsoft/signalr`.

**Spec:** `monkify-meta/specs/chat-per-game-type.md` (authoritative). Worktrees: `E:\Monkify\.worktrees\chat-per-game-type\{monkify-backend,monkify-front,monkify-meta}` on `feature/chat-per-game-type`.

## Global Constraints

- History limit: **100** messages per game type. Retention: `GeneralSettings.Chat.RetentionDays` (committed `2`, class default `7`; fallback `?? 7`).
- Group name: `chat:{gameTypeId}`. Event name: `string.Format(GameChatEndpoint, gameTypeId)` = `"{gameTypeId}/ChatMessage"`.
- Redis key: `ChatHistory:{gameTypeId}`.
- Payload JSON (broadcast + history): `{ id, displayName, text, sentAt }` camelCase, `sentAt` UTC ISO-8601.
- Hub `SendChatMessage(string gameTypeId, string gameId, string displayName, string text)`; `JoinChat(string gameTypeId)`; `LeaveChat(string gameTypeId)`.
- Unknown/inactive type: hub → silent return; history route → `ErrorMessages.ParameterNotFound` validation failure.
- EF mapping inline in `SpaceStrokerDbContext.OnModelCreating`; migration generated by `dotnet ef`, backfill SQL hand-added to the migration `Up` only.
- Mock-only config; API never writes chat to the DB.

`Services/Chat/MemoryChatHistoryStore.cs`:
```csharp
using System;
using System.Collections.Concurrent;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;
using SpaceStroker.Domain.Configs.Entities;
using SpaceStroker.Infrastructure.Contracts.Games;

namespace SpaceStroker.Infrastructure.Services.Chat
{
    /// <summary>
    /// In-process history for Redis-less runs (local without a Redis connection string). Per instance by
    /// nature — the deployed API is multi-instance and always has Redis, so it never uses this.
    /// </summary>
    public sealed class MemoryChatHistoryStore : IChatHistoryStore
    {
        private sealed class Room
        {
            public readonly object Gate = new();
            public List<GameChatMessageDto> Messages = new();
            public DateTime ExpiresAt;
        }

        private readonly ConcurrentDictionary<Guid, Room> _rooms = new();
        private readonly GeneralSettings _settings;

        public MemoryChatHistoryStore(GeneralSettings settings)
        {
            _settings = settings;
        }

        public Task AppendAsync(Guid gameTypeId, GameChatMessageDto message)
        {
            var room = _rooms.GetOrAdd(gameTypeId, _ => new Room());
            lock (room.Gate)
            {
                room.Messages.Add(message);
                if (room.Messages.Count > ChatHistory.Limit)
                    room.Messages.RemoveRange(0, room.Messages.Count - ChatHistory.Limit);
                room.ExpiresAt = DateTime.UtcNow.AddDays(ChatHistory.RetentionDays(_settings));
            }
            return Task.CompletedTask;
        }

        public Task<IReadOnlyList<GameChatMessageDto>?> ReadAsync(Guid gameTypeId)
        {
            if (!_rooms.TryGetValue(gameTypeId, out var room))
                return Task.FromResult<IReadOnlyList<GameChatMessageDto>?>(null);

            lock (room.Gate)
            {
                if (room.Messages.Count == 0 || room.ExpiresAt <= DateTime.UtcNow)
                    return Task.FromResult<IReadOnlyList<GameChatMessageDto>?>(null);

                return Task.FromResult<IReadOnlyList<GameChatMessageDto>?>(room.Messages.ToList());
            }
        }

        public Task RefillAsync(Guid gameTypeId, IReadOnlyList<GameChatMessageDto> messages)
        {
            var room = _rooms.GetOrAdd(gameTypeId, _ => new Room());
            lock (room.Gate)
            {
                var merged = room.Messages.Concat(messages)
                    .GroupBy(x => x.Id).Select(g => g.First())
                    .OrderBy(x => x.SentAt)
                    .TakeLast(ChatHistory.Limit)
                    .ToList();

                if (merged.Count == 0)
                    return Task.CompletedTask;

                room.Messages = merged;
                room.ExpiresAt = DateTime.UtcNow.AddDays(ChatHistory.RetentionDays(_settings));
            }
            return Task.CompletedTask;
        }
    }
}
```

`Services/Chat/RedisChatHistoryStore.cs`:
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text.Json;
using System.Threading.Tasks;
using Serilog;
using SpaceStroker.Domain.Configs.Entities;
using SpaceStroker.Infrastructure.Contracts.Games;
using SpaceStroker.Infrastructure.Services.Cache;
using StackExchange.Redis;

namespace SpaceStroker.Infrastructure.Services.Chat
{
    /// <summary>
    /// A game type's history as a Redis LIST (oldest at the head): RPUSH + LTRIM to the newest
    /// ChatHistory.Limit + EXPIRE RetentionDays, in one transaction. Shared by every API instance.
    /// Every failure is logged and swallowed — ReadAsync reports it as a miss so the DB fallback serves.
    /// </summary>
    public sealed class RedisChatHistoryStore : IChatHistoryStore
    {
        private static readonly JsonSerializerOptions Json = new(JsonSerializerDefaults.Web);

        private readonly IConnectionMultiplexer _redis;
        private readonly GeneralSettings _settings;

        public RedisChatHistoryStore(IConnectionMultiplexer redis, GeneralSettings settings)
        {
            _redis = redis;
            _settings = settings;
        }

        private TimeSpan Ttl => TimeSpan.FromDays(ChatHistory.RetentionDays(_settings));

        public async Task AppendAsync(Guid gameTypeId, GameChatMessageDto message)
        {
            try
            {
                var key = CacheHelper.GenerateChatHistoryKey(gameTypeId);
                var tx = _redis.GetDatabase().CreateTransaction();
                _ = tx.ListRightPushAsync(key, JsonSerializer.Serialize(message, Json));
                _ = tx.ListTrimAsync(key, -ChatHistory.Limit, -1);
                _ = tx.KeyExpireAsync(key, Ttl);
                await tx.ExecuteAsync();
            }
            catch (Exception ex)
            {
                Log.Error(ex, "Failed to append chat history for game type {GameTypeId}", gameTypeId);
            }
        }

        public async Task<IReadOnlyList<GameChatMessageDto>?> ReadAsync(Guid gameTypeId)
        {
            try
            {
                var key = CacheHelper.GenerateChatHistoryKey(gameTypeId);
                var values = await _redis.GetDatabase().ListRangeAsync(key, 0, -1);

                // An empty LIST does not exist in Redis, so zero values is always a miss.
                if (values.Length == 0)
                    return null;

                return Deserialize(values);
            }
            catch (Exception ex)
            {
                Log.Error(ex, "Failed to read chat history for game type {GameTypeId}", gameTypeId);
                return null;
            }
        }

        public async Task RefillAsync(Guid gameTypeId, IReadOnlyList<GameChatMessageDto> messages)
        {
            try
            {
                var key = CacheHelper.GenerateChatHistoryKey(gameTypeId);
                var db = _redis.GetDatabase();

                // A live append may have landed between the caller's miss and this refill — keep it.
                var current = Deserialize(await db.ListRangeAsync(key, 0, -1));
                var merged = current.Concat(messages)
                    .GroupBy(x => x.Id).Select(g => g.First())
                    .OrderBy(x => x.SentAt)
                    .TakeLast(ChatHistory.Limit)
                    .ToList();

                if (merged.Count == 0)
                    return;

                var tx = db.CreateTransaction();
                _ = tx.KeyDeleteAsync(key);
                _ = tx.ListRightPushAsync(key, merged.Select(x => (RedisValue)JsonSerializer.Serialize(x, Json)).ToArray());
                _ = tx.KeyExpireAsync(key, Ttl);
                await tx.ExecuteAsync();
            }
            catch (Exception ex)
            {
                Log.Error(ex, "Failed to refill chat history for game type {GameTypeId}", gameTypeId);
            }
        }

        private static List<GameChatMessageDto> Deserialize(RedisValue[] values)
            => values
                .Select(v => JsonSerializer.Deserialize<GameChatMessageDto>(v.ToString(), Json))
                .Where(x => x != null)
                .Select(x => x!)
                .ToList();
    }
}
```

```csharp
        public override async Task ProcessMessage(ChatMessagePersistedEvent message)
        {

            // few seconds of deploy-window chat that no room could ever serve — drop it rather than store
            // an unattributable row.
            if (message.GameTypeId == Guid.Empty)
            {
                Log.Warning("Dropping a legacy chat persist event with no game type.");
                return;
            }

            using var scope = ServiceScopeFactory.CreateScope();
            var context = scope.ServiceProvider.GetRequiredService<SpaceStrokerDbContext>();

            // Redelivery must not duplicate the message — the Id is the broadcast's own.
            if (await context.GameChatMessages.AnyAsync(x => x.Id == message.Id))
                return;

            context.GameChatMessages.Add(new GameChatMessage(
                message.Id, message.GameTypeId, message.GameId, message.DisplayName, message.Text, message.SentAt));

            try
            {
                await context.SaveChangesAsync();
            }
            catch (DbUpdateException) when (await context.GameChatMessages.AsNoTracking().AnyAsync(x => x.Id == message.Id))
            {
                // A concurrent redelivery won the insert — the message is already persisted.
            }
        }
    }
```

```csharp
        /// <summary>A game type's chat room. Prefixed so it can never collide with a round's (gameId) group.</summary>
        public const string ChatGroupPrefix = "chat:";

        public static string ChatGroupFor(Guid gameTypeId) => $"{ChatGroupPrefix}{gameTypeId}";

        /// <summary>
        /// Joins a GAME TYPE's chat room — the room outlives every round of that type, so the client joins
        /// once and does not rejoin on rollover. An unknown or inactive type joins nothing and says nothing
        /// (constraints.md §6).
        /// </summary>
        public async Task JoinChat(string gameTypeId)
        {
            var typeId = await ResolveActiveGameType(gameTypeId);
            if (typeId is null)
                return;

            await Groups.AddToGroupAsync(Context.ConnectionId, ChatGroupFor(typeId.Value));
        }

        /// <summary>Leaves a game type's chat room (a type switch). No validation: leaving is harmless.</summary>
        public Task LeaveChat(string gameTypeId)
            => Guid.TryParse(gameTypeId, out var typeId)
                ? Groups.RemoveFromGroupAsync(Context.ConnectionId, ChatGroupFor(typeId))
                : Task.CompletedTask;

        /// <summary>
        /// Game-type chat. Broadcasts a plain-text message (attributed to the client-resolved display name)
        /// to the type's room, appends it to the type's history (the last 100 served by
        /// GET /games/{parametersId}/chat), then publishes an event to persist it (off the realtime path).
        /// gameId is the round the sender is looking at — stored for audit only. Empty/over-length text, an
        /// empty name, a non-GUID round id, or a type that is not in the active catalogue are dropped
        /// without broadcasting, appending or persisting. The display name is client-supplied and trusted.
        /// See specs/chat-per-game-type.md.
        /// </summary>
        public async Task SendChatMessage(string gameTypeId, string gameId, string displayName, string text)
        {
            if (string.IsNullOrWhiteSpace(text) || text.Length > MaxChatMessageLength)
                return;

            if (string.IsNullOrWhiteSpace(displayName))
                return;

            if (!Guid.TryParse(gameId, out var roundId))
                return;

            var typeId = await ResolveActiveGameType(gameTypeId);
            if (typeId is null)
                return;

            var message = new GameChatMessageDto(Guid.NewGuid(), displayName.Trim(), text.Trim(), DateTime.UtcNow);

            // 1) Broadcast immediately — the realtime path never touches the DB.
            var chatEndpoint = string.Format(_settings.Games.GameChatEndpoint, typeId.Value);
            await Clients.Group(ChatGroupFor(typeId.Value)).SendAsync(chatEndpoint, message.AsJson());

            // 2) History (never throws — a Redis failure must not undo a delivered message).
            await _chatHistory.AppendAsync(typeId.Value, message);

            // 3) Persist asynchronously via the existing event -> consumer pattern.
            await _messageBus.PublishEventAsync(new ChatMessagePersistedEvent(
                message.Id, typeId.Value, roundId, message.DisplayName, message.Text, message.SentAt));
        }

        // Active = present in the CACHED catalogue. Deliberately not GetGameParametersById, which falls
        // through to the database on a miss and would put a query behind every crafted GUID.
        private async Task<Guid?> ResolveActiveGameType(string gameTypeId)
        {
            if (!Guid.TryParse(gameTypeId, out var typeId))
                return null;

            var active = await _gameService.GetAllActiveGameParameters();
            return active.ContainsKey(typeId) ? typeId : null;
        }
```

```csharp
    /// <summary>
    /// A game type's recent chat: the newest ChatHistory.Limit messages within Chat.RetentionDays, oldest
    /// first. Redis first; on a miss, the persisted rows — which then refill Redis. See
    /// specs/chat-per-game-type.md §6.4.
    /// </summary>
    public class GetGameChatHandler : BaseRequestHandler<GetGameChatRequest, IEnumerable<GameChatMessageDto>>
    {
        public GetGameChatHandler(IGameService gameService, IChatHistoryStore chatHistory, SpaceStrokerDbContext context, IMessaging messaging, GeneralSettings settings) : base(context, messaging)
        {
            _gameService = gameService;
            _chatHistory = chatHistory;
            _settings = settings;
        }

        private readonly IGameService _gameService;
        private readonly IChatHistoryStore _chatHistory;
        private readonly GeneralSettings _settings;

        public override async Task<IEnumerable<GameChatMessageDto>> HandleRequest(GetGameChatRequest request, CancellationToken cancellationToken)
        {
            // Unknown and deactivated collapse to the same vague ParameterNotFound (constraints.md §6).
            var parameters = await _gameService.GetGameParametersById(request.ParametersId);

            if (parameters == null || !parameters.Active)
                Messaging.ReturnValidationFailureMessage(ErrorMessages.ParameterNotFound);

            var cutoff = ChatHistory.Cutoff(_settings);

            var cached = await _chatHistory.ReadAsync(request.ParametersId);
            if (cached != null)
                return cached.Where(x => x.SentAt >= cutoff).ToList();

            var rows = await Context.GameChatMessages
                .AsNoTracking()
                .Where(x => x.GameTypeId == request.ParametersId && x.CreatedDate >= cutoff)
                .OrderByDescending(x => x.CreatedDate)
                .Take(ChatHistory.Limit)
                .Select(x => new GameChatMessageDto(x.Id, x.DisplayName, x.Text, x.CreatedDate))
                .ToListAsync(cancellationToken);

            rows.Reverse();

            await _chatHistory.RefillAsync(request.ParametersId, rows);

            return rows;
        }
    }
}
```

```ts
// caller then loads history); a call for the room we are already in is a no-op, which is what makes a
```
